# Marketing Mix Modeling: Channel ROI & Budget Optimization

## Objective
Quantify the sales contribution of TV, digital, paid social, and promotions
using a Bayesian Marketing Mix Model, and recommend an optimized budget
reallocation.

## Status
Phase 0: Project setup complete.

## Tech Stack
Python, PyMC-Marketing, PyMC, ArviZ, pandas, matplotlib

## Structure
- data/ - simulated weekly sales & spend data
- notebooks/ - EDA and modeling notebooks
- src/ - data generator, adstock/saturation transforms, model utilities
- outputs/ - decomposition results, ROI tables, charts
